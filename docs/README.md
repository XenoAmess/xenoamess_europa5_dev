## 知识归档原则

- EU5 特有的 metadata、脚本方言、scope、GUI、日志、存档和 Mod Tools 行为记录在本仓库。
- Paradox 共性经验可参考 `D:\workspace\ck3_eternal_recurrence\docs` 和 `D:\workspace\xenoamess_stellaries_dev\docs`，但必须经当前 EU5 exact build 验证后才能成为本仓库规则。
- 新事实要同时写明证据来源、适用 build 和能力边界；计划、推测和实测结论必须明确区分。
- 产品文档可以增加更严格的门禁，但不能降低本知识库的完成标准。
