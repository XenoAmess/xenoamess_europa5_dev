# 献给白绮的附属地整合 0.2.0

发布日期：2026-09-15

Workshop item：3800505751

## 玩家变化

- “整理殖民领地区”泛化为“整合附属地”。
- 同一个附属国互动现在支持所有合格的直属领土型附属国，殖民领与非殖民领一视同仁。
- building、pop、army 型附属对象、没有有效首都的对象、独立国家和更下层附属国不能成为
  直接目标；更下层附属国仍可贡献目标 Region 内的待转让地点。
- 新增效果侧完整复核：如果确认到执行之间目标、战争、Region、工作量或类型上限发生变化，
  操作不会转让任何地点。
- 土司遵守 15 地点上限；批量整合只有在全部待转让地点加入后仍不超过 15 时才可执行，
  不会部分转让。
- 11 种内置语言的标题、动作、说明、确认警告和禁用原因改为通用附属地语义。
- 正式缩略图改为白绮人物形象与附属地汇聚主题的新图。

## 兼容性

- 继续使用 product key colonial_region_transfer、stable ID
  xenoamess.colonial_region_transfer、脚本 key xcrt_cleanup_colonial_region 和原
  Workshop item；0.1.0 存档与已公开 key 不迁移。
- 面向 Europa Universalis V 1.3.11 (Pavia)，Steam Build 24187685。
- 只追加一个 country interaction 与其 xcrt_ scripted triggers，不使用 replace path。

## 已知限制

- 目标范围仍固定为目标首都所在 Region，不提供 Area、Province 或框选模式。
- 转让可能包括其他附属国首都或最后地点；EU5 可能迁都或清理该国。产品只警告风险，
  不承诺具体生命周期结果。
- AI 永不主动使用。
- 除简体中文外的本地化只做静态覆盖。
