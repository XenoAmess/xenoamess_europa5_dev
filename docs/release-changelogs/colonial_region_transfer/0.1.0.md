## 玩家变化

- 新增直属殖民领互动“整理殖民领地区”。
- 一次性把目标殖民领首都 Region 内由宗主及其任意层级附属国持有的地点划给目标。
- 不直接影响 Region 外地点或体系外国家。
- 战争、无可转让地点或宗主首都处于同一 Region 时禁用；AI 不会主动使用。
- 提供 EU5 当前 11 种语言本地化，非中文标题统一使用 `Vivhite`。

## 兼容性与限制

- 面向 Europa Universalis V `1.3.11 (Pavia)`、Steam Build `24187685`。
- 只追加 country interaction，不使用 replace path。
- 转让包含其他附属国首都与最后地点，可能由游戏引擎触发迁都、失效首都清理或国家消失；互动确认框会明确警告。
- 简体中文已完成运行时与 OCR 验收；其他十种语言为静态覆盖。
- Open Kaishek EU5 profile 缺失保持为独立 `tool-coverage RED`。
